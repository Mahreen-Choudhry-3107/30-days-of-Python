# Project 01: Number Guessing Game

**Week 1 project** | Difficulty: ⭐

## Features

- Three difficulty levels (range and attempt limits differ).
- Input validation for non-numeric and out-of-range values.
- Higher/lower hints and remaining attempts.
- Score tracking across multiple rounds.

## Run

```bash
python main.py
```

## Concepts used

Variables, conditionals, loops, dictionaries, functions, `random`, and `if __name__ == "__main__"`.

## Extension ideas

- Save the best score to a file (after Day 11).
- Let the player guess the computer's number, then let the computer guess yours using binary search.
- Add a timer using `time.time()`.
